# Financial Stock Prediction Application (README to be updated at a later time)
The goal of this project is to develop a robust application leveraging machine learning algorithms for stock prediction on real world datasets.

### Get Started
1. **Install Required Libraries**

```bash
pip install -r requirements.txt
```

2. **Getting the Data**

The Datasets are contained in the **data** folder, separated into two subfolders: Processed, Raw. Processed contains the feature engineered data, while Raw contains the initial preprocessed data.

3. **Code Organization**
- The **notebooks** folder contains our code executions used to implement specific tasks, such as model training and evaluation and feature engineering. There will be subfolders (e.g. cleaning, feature_engineering) that differentiate between the tasks.
- **src** contains the code modules, especially for the models we have built. We can import scripts from **src** into our notebook files to run.
- **models** (tbd; perhaps this contains the model scripts/modules or the paths)
- **app** contains the code to the dashboard used to run our stock predictions
